## 浏览器检查

使用独立 QA 数据库，未配置外部模型密钥。桌面 1440×1000，手机 390×844。

- 首次登录强制改密、退出并重新登录。
- 在工作台新建客户，统计和活动列表实际更新。
- 客户详情保存单条消息，选择原文证据生成 Mock 提案。
- 提案页面核对五维差异、原始证据和八维 delta 后批准；正式画像从 v0 变为 v1，并显示证据 ID 与更新时间。
- 手机端客户详情在档案、聊天、AI/历史之间切换，已修复隐藏栏仍出现的问题；聊天表单无页面横向溢出。
- 桌面和手机截图均已人工检查，布局无明显遮挡或文字截断。

## 验证边界

真实 AI API 的成功、格式异常与脱敏请求使用模拟 HTTP 响应验证；未使用真实密钥调用付费服务。第三方接口兼容性及目标内网的防火墙、HTTPS、运维服务账号权限仍须在正式部署环境确认。没有执行负载容量或大规模用户测试；本项目定位为小团队单进程 SQLite MVP。
